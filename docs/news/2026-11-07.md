This records implementation merged into GitHub, not a general-availability announcement. Signed-in end-to-end testing of the latest Chat and background-task flow remains outstanding. ChatLegal provides legal information, not legal advice, and is not a solicitor.

## A clearer place to keep your Chat

The signed-in app gained a three-pane layout: Chat history on the left, the conversation in the centre, and supporting information or a file preview on the right. Side panes can collapse to give the conversation more room. Chats are stored against the signed-in account, and the list supports opening, searching, renaming and archiving. Archive hides a Chat rather than deleting its history. The interface now consistently calls these conversations **Chats**.

## Easier conversations and reading

New Chats start with an explanation of the service's limits and questions about location and relevant papers. Choice cards let people answer structured questions without typing everything out. Outbound text has a retry queue that keeps waiting messages through connection failures and reloads.

Assistant replies now support Markdown headings, lists, emphasis and links. Scrolling follows new replies until you scroll up; a return-to-bottom control lets you resume. For a long answer, the view holds near your question so you can read down without being pulled to the bottom.

The AI-generated-information reminder moved from repeated reply introductions to the sticky footer. The Welsh-language footer line was removed; this does not introduce a translated product.

## Keeping documents alongside a Chat

The implementation adds a personal Library and files attached to an individual Chat. PDF, Word and Markdown uploads can be stored with the open Chat, and an existing Library file can be attached without moving the original. The right pane previews supported files; Word files remain downloads rather than rendered previews.

Optional indexing can extract text from PDFs and Word documents as well as text files. It requires separate configuration, does not read scanned PDFs with OCR, and is **not yet connected to Chat answers**. Uploading a file should not be taken to mean the assistant has searched or read it.

## Foundations for the assistant

Four linked changes build the runtime behind Chat:

- **G-00:** a LiteLLM-backed connection for streamed replies, enabled only when configured.
- **G-01:** a Concierge that can ask follow-up questions using choice cards and describe progress in plain language.
- **G-02:** a TaskRunner handoff for background work, returning a summary to the Concierge rather than exposing internal tool output.
- **G-03:** a typed tool bus with input checks and timeouts, plus a durable task queue designed to recover interrupted work after a restart.

These are runtime foundations, not completed legal-tool integrations. The tool bus still contains demonstration tools (`echo`, `timed_noop`, `count_words`); domain integrations and document-grounded Chat answers remain pending. The latest signed-in handoff, queue and tool-bus flow still needs end-to-end verification.

Draft and unresolved verification points remain visible; these pages are not presented as professionally reviewed legal advice. Subtle motion respects reduced-motion preferences.
